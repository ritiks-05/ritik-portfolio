## Profile photo
`assets/profile.png` is embedded in the hero section.

## Contact form
The form opens the visitor's email application and pre-fills the enquiry. It does not send or store submissions on a server.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
Push all files and the `assets` folder to GitHub, then enable GitHub Pages in repository Settings → Pages.
